# LED Memory Game
A UTM Robotics Workshop, covering the basics of LEDs, user inputs, and control statements!


Participants created an LED memory game! Once players start playing the project, they must remember a sequence of LEDS tat have blinked in a level. The game gets harder as players progress, as the sequence builds on the previous levels!

This was a super fun project to make, my partner had tons of fun doing the hardware wiring!
